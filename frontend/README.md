# VehicleVoice — Frontend

React + Vite push-to-talk UI for the VehicleVoice voice-search MVP.
Push-to-talk mic capture, typed-transcript fallback, slot inspector, top-3
vehicle cards, spoken-response panel (audio playback ready to plug in when
TTS lands), and per-stage latency.

## Requirements
- Node 18+ / npm, or Bun.

## Develop
```bash
cd frontend
npm install
npm run dev          # Vite dev server on :5173, proxies /api -> 127.0.0.1:8000
```

Start the backend on :8000 in another terminal (from the repo root):
```bash
../.venv/bin/uvicorn backend.main:app --port 8000
```
Open http://localhost:5173 — typed queries are fully functional end to end.

## Build (production)
```bash
cd frontend
npm install
npm run build        # outputs to frontend/dist
```
The FastAPI backend mounts `frontend/dist` automatically when it exists, so the
live site just needs the backend running from the repo root on the public port:
```bash
cd <repo root>
.venv/bin/uvicorn backend.main:app --host 0.0.0.0 --port 3000
```

## Voice path (awaiting the STT/TTS milestone)
- **Mic → backend:** press-and-hold records (MediaRecorder) and transcodes to
  16-bit PCM WAV (`src/audio.js`), then POSTs it as multipart/form-data to
  `/api/voice/audio` with fields `session_id` and `audio`
  (`src/api.js` → `postVoiceAudio`). That endpoint is **not implemented yet**,
  so today a 404 shows a graceful notice and the app falls back to typed input.
  When the backend STT endpoint lands it should return the same payload shape
  as `POST /api/voice` (with `transcript` filled) and this client will work
  unchanged (see the contract in `src/api.js`).
- **Playback:** the `<audio>` element is disabled until the response contains
  an `audio_url` (or a `/api/tts` endpoint is added). Until then the spoken
  text is shown as text. Wire TTS by setting `speechUrl` in `App.jsx`.

## Layout
```
frontend/
  index.html         entry html
  vite.config.js     dev proxy to backend (:8000)
  src/
    main.jsx         React bootstrap
    App.jsx          whole UI (state + components)
    api.js           backend client (session id, /api/voice, /api/voice/audio)
    audio.js         MediaRecorder -> WAV capture helpers
    styles.css       plain CSS
  dist/              build output (regenerated by `npm run build`)
```
